# Visual Identity Notes

This repository should look like a technical companion to a global-change
science paper: clean, modern, and highly readable.

## Direction

- Scientific first: article, data products, and workflow should be immediately
  visible.
- Technical but not crowded: badges, workflow, datasets, and scripts should be
  scannable.
- Global/climate signal: use the custom banner, institutional logos, and world
  sample figures already present in the repository.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Deep atmosphere | `#0d1821` | Banner background and technical tone. |
| Ocean teal | `#46a3a3` | Main accent and DOI/data emphasis. |
| Soil gold | `#d29f36` | Soil texture and carbon-flux highlight. |
| Vegetation green | `#89b77f` | Biome and ecological accent. |
| Flux orange | `#d56b4a` | Warming/respiration contrast. |
| Paper white | `#f7fbfc` | Primary text over dark background. |
